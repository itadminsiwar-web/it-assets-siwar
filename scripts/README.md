# سكريبت متابعة باقات WE (الجيجات وميعاد التجديد)

```
we_usage.py (على جهاز في المكتب، كل ساعة)
   ← يدخل my.te.eg بيوزر وباسورد كل خط
   ← يبعت المتبقي والتجديد لـ Google Sheets (Code.gs)
   ← نظام IT Administration بيقرا الشيت كل 5 دقايق ويحدّث "باقات الإنترنت" والتنبيهات
```

## 1) الشيت (مرة واحدة)
1. افتح شيت جوجل اللي النظام بيقرا منه (نفس ID اللي في "المزامنة والإعدادات" في النظام).
2. Extensions ← Apps Script ← الصق `google-sheet/Code.gs` ← غيّر `SECRET` لكلمة سرية من عندك.
3. Deploy ← New deployment ← النوع **Web app** ← Execute as: **Me** ← Who has access: **Anyone** ← Deploy ← وافق على الصلاحيات.
4. انسخ رابط الـ Web app (بينتهي بـ `/exec`).

## 2) السكريبت على جهاز المكتب (Windows)
1. لازم يكون Python 3 متثبت (من python.org — علّم على "Add to PATH").
2. افتح فولدر `we-usage` وشغّل **install.bat**. هيثبّت المكتبات ويعمل `config.json` ويجدول التشغيل كل ساعة.
3. افتح `config.json` واكتب:
   - `sheet_webapp_url`: رابط الـ Web app من الخطوة 1
   - `sheet_secret`: نفس الـ SECRET
   - `lines`: لكل خط **الكود في النظام** (NET-001…) ورقم الخط الأرضي بكود المحافظة (`0223456789`)
4. **الباسورد:** الأفضل ماتكتبهوش في الملف. شغّل الأمر ده لكل خط واكتب الباسورد لما يطلبه:
   ```
   python we_usage.py --set-password NET-001
   ```
   الباسورد بيتحفظ في Windows Credential Manager. ولو حابب، اكتبه في `password` جوه config.json.
5. جرّب يدوي: `run.bat`. لكل خط هيطبع: "✓ NET-001: متبقي 60 من 200 جيجا · التجديد 2026-12-01".

## لو حاجة مش شغالة
- `run.bat --debug` بيطبع رد WE الخام. ابعتلي الناتج **بعد ما تشيل منه أي بيانات شخصية**.
- `run.bat --dry-run` بيجيب البيانات ويكتب `output/latest.csv` بس، من غير ما يبعت للشيت. الملف ده تقدر تستورده يدوي من النظام: المزامنة والإعدادات ← استيراد CSV ← "الاستهلاك".
- **تنبيه:** my.te.eg ملوش API رسمي. السكريبت بيكلم نفس العناوين اللي الموقع نفسه بيستخدمها، فلو WE غيّرت الموقع أو حطت كابتشا، الدخول هيفشل لحد ما السكريبت يتعدّل.
- السكريبت لازم يشتغل من جهاز في مصر. موقع WE ممكن يرفض الطلبات اللي جاية من سيرفرات بره.

## الأمان
- الباسوردات **مش** بتدخل نظام IT Administration خالص، ولا الشيت. بتفضل على جهاز السكريبت بس (Credential Manager).
- الشيت لازم يبقى "أي حد معاه الرابط يقدر يشوف" عشان النظام يقراه، فمتحطش فيه بيانات حساسة.
