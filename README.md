# Three Pillars — نظام تقنية المعلومات (نسخة مستقلة)

إدارة الأصول والتجديدات + دورة الموظف (التعيين 0–8 والإخلاء X1–X9) — من غير النظام المالي والتسويق.

## التشغيل
افتح `it.html` (أو `index.html`) في Chrome أو Edge.

| الحساب | الإيميل | الباسورد |
|---|---|---|
| المدير | admin@example.com | Admin@123 |
| مسؤول IT | it@example.com | It@12345 |
| الموارد البشرية (دورة الموظف بس) | hr@example.com | Hr@12345 |

صفحة التقديم العامة للمرشحين (QR): `apply.html`

## تغيير اسم الشركة واللوجو
**كل حاجة في ملف واحد: `js/brand.js`**

1. افتح `js/brand.js` وغيّر:
   - `company` اسم الشركة بالعربي، و`companyEn` بالإنجليزي
   - `systemName` اسم النظام في الشريط العلوي
   - `emailDomain` دومين الإيميلات
   - `branches` الفروع
   - `accent` لون أساسي اختياري (مثلاً `'#0f766e'`)
2. اللوجو: حط صورتك في فولدر `img` بنفس الاسم:
   - `img/logo.png` للخلفية الفاتحة
   - `img/logo-white.png` للوضع الليلي وشاشة الدخول
   (أو اكتب اسم ملفك الجديد في `logo` و`logoWhite`)
3. افتح النظام تاني بـ Ctrl+F5.

الاسم الجديد بيتطبق على الشاشات والإقرارات المطبوعة، وكمان على البيانات اللي كانت مسجلة بالاسم القديم.

## إضافة المواقع والاشتراكات المدفوعة
**من السيستم (الأسهل):**
- **الاشتراكات ← التراخيص ← "+ اشتراك"**: الاسم، الفئة "مواقع ومنصات مدفوعة"، رابط الموقع، حساب الدخول، التكلفة والعملة، الدورة (شهري / سنوي)، تاريخ التجديد، ومين بيستخدمه.
- **الاشتراكات ← الدومينات و SSL والهوستنج ← "+ إضافة"**: الدومينات وشهادات SSL والاستضافة.

**من ملف (لو عندك قايمة كبيرة):** املا الملفات اللي في فولدر `templates` بـ Excel:
| الملف | يتستورد في |
|---|---|
| `1-المواقع-والاشتراكات-المدفوعة.csv` | الكود لازم يبدأ بـ `LIC-` |
| `2-الدومينات-و-SSL-والهوستنج.csv` | الكود `DOM-`، والصنف: دومين / SSL / هوستنج |
| `3-باقات-الإنترنت.csv` | الكود `NET-`، والتكلفة بالجنيه |

وبعدها في السيستم: **المزامنة والإعدادات ← اختار التاب ← ⬆ استيراد CSV**.
(أو حط نفس الأعمدة في تاب بنفس الاسم في Google Sheets، والمزامنة هتقراها لوحدها.)
التواريخ تتكتب `2026-12-31` أو `31/12/2026`. أي صف فيه غلطة بيظهر في "أخطاء المزامنة".

## البدء ببيانات حقيقية
في `js/config.js` خلّي `autoDemo: false`، وبعدين امسح بيانات الديمو من المتصفح:
F12 ← Application ← Local Storage ← امسح `it_assets_tp_v1`.
البيانات بتتحفظ في المتصفح باسم `it_assets_tp_v1`، مستقلة عن النظام الكامل.
